# UX & UI Documentation

This directory centralizes all design specifications, design system tokens, interaction flows, and user research for OneSquad interfaces (including `apps/mockup`).

## Design system

- [`design-system/`](./design-system/README.md): Design tokens, UI component specifications, and accessibility guidelines.

## Optional folders

Projects can create these folders if they are useful for their way of working. They are recommendations, not requirements:

- `flows/`: User journey maps, navigation flows, and interactive state diagrams.
- `research/`: User interview findings, usability testing reports, and feedback synthesis.

## Design Philosophy

- **Decathlon Design Alignment**: UI patterns must align with Decathlon brand guidelines and digital design standards.
- **Accessibility (a11y)**: All components must meet WCAG 2.1 AA contrast and navigation standards.
- **Consistent Tokens**: Spacing, colors, and typography should derive from defined design tokens.
