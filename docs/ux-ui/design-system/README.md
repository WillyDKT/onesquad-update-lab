# Product design system

Use this folder to define and document the design system for your product. It provides a shared reference for designers and developers when creating consistent interfaces and mockups.

Depending on your product, you can document:

- Visual foundations such as colors, typography, spacing, and icons.
- Reusable components and their states, interactions, and usage guidelines.
- Accessibility requirements, including contrast, labels, and keyboard navigation.
- Links to existing design libraries, resources, or approved references.

Adapt this documentation to your product and update it as your design system evolves. If a design system already exists, link to it here rather than duplicating it.
