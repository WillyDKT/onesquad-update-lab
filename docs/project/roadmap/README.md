# Project Roadmap & Milestones

This directory tracks delivery roadmaps and high-level release milestones for OneSquad.

## Naming Conventions

- Strategic or quarterly roadmap: `roadmap-YYYY-QX.md` (e.g. `roadmap-2027-Q1.md`)
- Major version roadmap: `roadmap-vX.Y.md` (e.g. `roadmap-v1.0.md`)
- Template: [`template-roadmap.md`](./template-roadmap.md)

## Lifecycle & Review

Roadmaps are reviewed monthly or quarterly.
- `Draft`: Proposed milestone schedule.
- `Committed`: Confirmed and resourced by engineering and product teams.
- `Delivered`: All milestone goals achieved.
- `Archived`: Past roadmap retained for historical reference.
