# Product Documentation

This directory centralizes all product vision, feature specifications, user stories, and training material for OneSquad.

## Product Principles

1. **User-Centric Value**: Every feature specification must clearly articulate the user problem and expected business outcome.
2. **Explicit Acceptance Criteria**: PRDs must outline testable criteria before engineering begins.
3. **Traceability**: PRDs link directly to architectural decisions in `../../architecture/adr` and tasks in `../tasks`.
