# Support Procedures & SOPs

This directory contains Standard Operating Procedures (SOPs), user issue triage workflows, and escalation guides for OneSquad tier 1 & 2 support.

## Naming Conventions

- Procedure files: `sop-<process-name>.md` (e.g. `sop-user-access-request.md`, `sop-data-correction.md`)
- Template: [`template-support-sop.md`](./template-support-sop.md)

## Support Tiers

- **Tier 1 (Help Desk)**: Basic credential resets, onboarding guidance, and general FAQs.
- **Tier 2 (Platform Support)**: Triage of ingestion discrepancies, API key permissions, bug reproduction.
- **Tier 3 (Core Engineering)**: Code-level bug fixes, production database interventions, infrastructure incidents.
