# Mockups and prototypes

This folder holds mockups generated or imported for your product. It keeps mockups, documentation, and project code
together in one place.

We previously used Figma to create mockups. Because its available credits are too limited for our needs, we can now use
Copilot to generate them directly in this repository.

## Create a mockup

Choose the approach that fits your situation:

- **You already have a Figma mockup:** Retrieve the code generated by Figma, if available, and copy it into this folder.
  Ask Copilot to help you adapt or run it if needed.
- **Your product already exists:** Give Copilot a screenshot of the production version and describe the improvement you
  want. Copilot can use it as a starting point to generate a mockup here. Avoid sharing sensitive data in the screenshot.
- **Your product does not exist yet:** Describe your needs, intended users, screens, and interactions to Copilot. It can
  generate an initial mockup in this folder that you can refine together.

In all cases, specify what matters to your project, such as colors, existing components, screen states, and accessibility
requirements. Then review the visual result and interactions: the generated mockup is a proposal to refine, not automatic
validation of the requirements.

## Choose a technology

React or the front-end technology already used by your project is recommended, as it may make some elements easier to
reuse. Another technology is also possible if it better suits the project and respects its technical decisions.

The code primarily serves to create and evolve the mockup. For designers, the visual result and proposed experience are
what matter most. Prototype code is not necessarily ready for production and must be reviewed before reuse.
