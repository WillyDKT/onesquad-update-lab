# Frontend Application (`apps/front`)

Production web application client for OneSquad.

## Getting Started

1. Place frontend source code, components, routes, and styles in this directory.
2. Implement user flows defined in [`../../docs/ux-ui/flows/`](../../docs/ux-ui/flows/).
3. Align components with the design system defined in [`../../docs/ux-ui/design-system/`](../../docs/ux-ui/design-system/).
